# AquaGo — скачать для Android

**Последняя версия:** https://github.com/IlyasQa02/aquago-download/releases/latest/download/AquaGo.apk

Откройте ссылку на телефоне, скачайте и установите. Начиная с 1.4.0 приложение
обновляется само: мелкие правки приходят «по воздуху», о новой сборке приложение
напомнит и предложит скачать.

- `update.json` — что сейчас актуально (читает приложение при запуске)
- `bundles/` — обновления «по воздуху»
